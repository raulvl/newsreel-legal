Privacy Policy

NewsReel · Last updated 24 October 2026

NewsReel ("the App") is a personal video-generation tool operated by a single individual. This policy explains exactly what data the App handles. It is short because the App is deliberately small: one operator, no analytics, no advertising, no third-party trackers, and no other users.

1. What the App collects

The only data the App receives from TikTok, after the Operator authorises it, is:

DataSourcePurpose
open_idTikTok Login Kit Identifies which account an upload belongs to
Display name, avatar URLLogin Kit (user.info.basic) Shown only to the Operator as confirmation
OAuth access & refresh tokensTikTok Login Kit Authenticating API calls
Video files the Operator uploadsGenerated by the App Sent to TikTok via the Content Posting API

The App does not collect TikTok passwords, follower lists, direct messages, watch history, or any data about other TikTok users.

2. Where data is stored

All data is stored locally on the Operator's own computer:

  • OAuth tokens: a local file readable only by the Operator's user account
  • Generated videos, captions and logs: local files
  • Episode metadata: a local database

No cloud database, no remote server, and no third-party hosting is used.

3. What is shared

Nothing is sold, rented, or shared with third parties. The only outbound transfers are:

  • to TikTok's API, to upload content the Operator approved;
  • to news publishers' public feeds, to read headlines (no personal data is sent);
  • to a language-model API, to draft a script from those public headlines (no TikTok data is sent).

4. Retention

Tokens are kept until the Operator revokes access in TikTok's Manage app permissions or deletes them locally. Generated videos and metadata are deleted at the Operator's discretion. Nothing is retained after revocation beyond local files the Operator removes.

5. Security

Tokens are stored in a file excluded from version control. API traffic uses HTTPS. Because the App runs on a single machine with no server, there is no shared credential store to breach.

6. Children

The App is not directed at children and has no users other than its Operator.
